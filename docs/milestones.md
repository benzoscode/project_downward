# 里程碑计划 — 《downward》

> 本文档定义 AI 集中交付的迭代划分。每个里程碑 = 一次"集中交付周期"：确认清单 → AI 独立执行到底 → 自验证 → 交付审阅。
> 验收标准必须是**机器可验证或截图可审阅**的，禁止主观描述。
> 完成一个里程碑后更新本文档状态，并同步更新 `godot_project/docs/architecture.md`。

状态标记：`[ ]` 未开始 / `[~]` 进行中 / `[x]` 已验收

---

## M0：工程地基 [x]

**目标**：跑通"AI 开发 → 自动验证 → 截图审阅"的完整回路，产出后续所有工作的基础设施。

- [ ] `project.godot` 渲染配置：480×270 原生分辨率、viewport 整数倍缩放、像素 snapping、Nearest 过滤
- [ ] Input Map：`move_left/right`、`jump`、`toggle_lamp`、`whistle`、`switch_control`、`interact`（A/D/空格/F/Q/R/E）
- [ ] 目录结构按 AGENTS.md §4 建立
- [ ] `tools/`：截图脚本（headless 截指定场景指定帧）、场景冒烟验证脚本
- [ ] `GameState` Autoload 骨架（已获道具、当前房间、检查点位置）
- [ ] 首批占位素材：地形瓦片、玩家、道具图标（按 AGENTS.md §7 尺寸表，AI 生成纯色剪影）
- [ ] TileSet（16×16，含物理层）+ `room_base.tscn` 模板（出生点、相机边界、出入口标记、环境光节点）
- [ ] `docs/`：architecture.md 骨架、decisions.md（记录分辨率 B 方案决策）、building_blocks.md 骨架

**验收**：headless import 0 错误；冒烟测试跑通 room_base 模板场景；产出首张自动截图。

## M1：玩家 3C [x]

**目标**：角色控制器手感达到策划案数值，全部参数可机器断言。

- [x] A/D 移动：3 格/秒，起步/停止带加速度惯性（策划案 §二(一)）
- [x] 空格跳跃：固定 3 格高度；含土狼时间（0.1s）与跳跃缓冲（0.1s）提升手感
- [x] 碰撞判定 12×20px，玩家占位精灵 16×24（idle/run/jump 三态剪影帧）
- [x] 相机：跟随玩家、阻尼平滑、受 room_base 边界限制
- [x] 验证场景 `tools/verify/verify_player.gd`：自动断言移动速度、跳跃高度（±0.1 格）、惯性存在

**验收**：验证场景全绿；测试房间内跑跳 GIF/截图；`architecture.md` 记录角色状态机。

## M2：照明灯与光照系统 [~]

**目标**：核心机制"光暗二元"成立，这是整个游戏的地基。

- [x] 全局黑暗：CanvasModulate 暗环境 + 玩家 2 格半径微弱自发光（关灯状态）
- [x] F 开关灯：60° 锥形光、6 格射程、方向实时跟随鼠标（策划案 §二(二)1）
- [x] 光线遮挡：石柱等地形挡光（TileSet 遮光层 + 物理射线判定）
- [x] 光敏水晶积木：被锥形光持续照射 2 秒激活（带进度视觉反馈），发信号
- [x] 光照判定 API：`LightSystem` 提供"某点是否被玩家灯光照到"查询（供 Boss/机关复用）
- [x] 验证场景：断言水晶在照射 2s 后激活、遮挡后不激活、关灯不激活

**验收**：验证场景全绿；开/关灯对比截图；锥形跟随鼠标的连续截图。

## M3：机关积木库（第一批）

**目标**：策划可零代码搭建前 3 个房间所需的全部积木。

- [ ] 狮子头按钮（按下触发，发 `activated` 信号，可配一次性/可重复）
- [ ] 问号门 / 石门（`door_id` 关联，开启动画 + 可配常开/条件开关）
- [ ] 地刺（触碰即死，发信号给房间重生逻辑）
- [ ] 水体（可穿越区域，浸入视觉反馈：半透明 + 减速）
- [ ] 梯子（攀爬区域）
- [ ] 宝箱（E 开启，发出道具）
- [ ] 道具拾取物（通用：照明灯/羽翎靴/召唤哨/宝石，拾取后写入 GameState）
- [ ] 房间重生点 + 死亡重生流程（回入口，机关状态按策划案保留）
- [ ] 演示房间 `rooms/demo_room.tscn`：串联全部积木，供审阅手感
- [ ] `building_blocks.md`：每个积木的用途、参数、连线方式、截图

**验收**：演示房间冒烟通过 + 全程截图；搭建手册人类可读。

## M5：召唤哨与老鼠 [~]

**目标**：双体协作机制成立，这是后期解谜与 Boss 战的核心。

- [x] Q 召唤/收回老鼠；老鼠死亡后 5 秒冷却（策划案 §二(二)3）
- [x] R 切换操控：玩家静止、相机切换到老鼠、切回后老鼠停留原地
- [x] 老鼠控制器：5.2 格/秒、2 格跳 + 1.5 格二段跳、6×6 判定、可过 1 格窄缝
- [x] 老鼠 0.8s 输入延迟（第 9 房间机制，做成可开关的 export 参数）
- [x] 小型压力板（仅老鼠可踩）/ 大型压力板（两者皆可）
- [x] 验证场景：断言延迟生效、切换后相机目标、窄缝通过性、压力板权限

**验收**：验证场景全绿；双体协作开门演示截图。

## M6：机关积木库（第二批）+ 特殊机制 [~]

**目标**：覆盖第 4/5/8/9/10/11 房间全部机制积木。

- [x] 交替平台（红/绿双组交替显隐，周期可配；消失瞬间站立判定安全处理）
- [x] 摇杆 + 移动平台（按住 E 平台移动、松开复位，路径可视化）
- [x] 双按钮门（两个按钮同时处于按下态才开门，松手延迟 2s 关闭）
- [x] 机关滞后组件（按钮触发后延迟 N 秒生效，如石桥升起）
- [x] 草丛光透（灯光照射时显现隐藏通道入口）
- [x] 致幻延迟视觉（画面渲染延迟 1s 的 Shader/缓冲方案 + 教学用虚空平台）—— 技术风险最高项，如 1 帧缓冲方案不可行，降级为"输入延迟 1s"并在交付说明中记录
- [x] 水滴顺序机关（第 2 房间：装置 → 水滴 → 水面颜色 → 颜色按钮组，做成可配置序列的组合积木）

**验收**：每积木独立冒烟 + 演示场景截图；building_blocks.md 补全。

## M7：Boss AI（地底猎食者）

- [ ] 五状态状态机：巡逻/警戒/追击/搜索/分心，转换条件按策划案 §二(四)2 表格实现
- [ ] 光源感知：开灯玩家 ≤8 格追击、>8 格警戒；环境光位置同理（复用 M2 光照判定 API）
- [ ] 老鼠优先级：老鼠 ≤6 格即转分心，优先于玩家
- [ ] 接触扑杀：玩家死亡回检查点；老鼠消失进 5s 冷却
- [ ] 搜索 10s 超时回巡逻；追击沿玩家路径（简化：直线 + 绕障，不做完整寻路）
- [ ] Boss 占位动画：128×128 剪影 + 触须状态（低垂/竖起/展开）用颜色或形状区分
- [ ] 验证场景：覆盖全部状态转换路径与优先级冲突场景

**验收**：验证场景全绿；五状态切换演示 GIF。

## M8：房间连通与检查点系统

**目标**：12 房间地图骨架可流通，存档/复活成立。

- [ ] 房间过渡：出入口触发区 → 切场景 + 淡入淡出；房间连接表按策划案配置
- [ ] 能力门验证：钥匙门、二段跳高台、老鼠窄缝等在游戏中正确拦截/放行
- [ ] 检查点：每房间入口自动存档（位置/道具/机关状态）；死亡回最近检查点
- [ ] 用占位灰盒（TileMap 简笔）连通全部 12 房间骨架，验证无卡死路径、无不可达区域
- [ ] 狭长通道等过渡空间按策划案连接关系实现（3↔11、3→12 等）

**验收**：脚本自动遍历 12 房间连接图断言连通性；道具门拦截测试全绿。

**目标**：游戏高潮关卡完整可玩（由 AI 灰盒搭建，策划后续精修）。

- [ ] 三层结构：潜行层 / 追赶层（屏障 60s 四档衰减 + 三项操作）/ 宝石逃离层

| 时机 | 人类工作 |
|---|---|
| M3 后 | 策划用积木搭建房间 1-3 |
